dq 电流平面：电流极限圆与电压极限圆

工作点必须同时落在电流极限圆（逆变器/电机发热限制 |i| ≤ Imax）和电压极限圆（母线电压限制，圆心 (−ψf/L, 0)，半径 Vmax/(ωeL)）之内。转速越高电压圆越小；当它缩到 q 轴以左，只能向负 id 方向移动——这就是弱磁。水平虚线 = 当前转矩对应的等转矩线。

电机参数

1. 电机为什么会转

定子三相绕组通电后在气隙中产生磁场；转子上的永磁体也有自己的磁场。两个磁场像两块磁铁一样相互吸引/排斥，转矩大小与二者夹角的正弦成正比：

Te = 1.5·p·ψf·|is|·sin β

β = 90° 时同样电流产生的转矩最大。想让电机一直转，就要让定子磁场始终领先转子 90° 电角——而转子在转，所以定子磁场必须跟着转子同步旋转。

2. 三相电流 → 旋转磁场

三相绕组在空间上互差 120° 电角，通以时间上互差 120° 的正弦电流，三个脉振磁场叠加成一个幅值恒定、匀速旋转的磁场。控制三相电流的幅值和相位，就能决定这个旋转磁场的大小和方向。

3. Clarke 与 Park 变换

Clarke 把三个相电流合成一个二维矢量 (iα, iβ)；Park 再把它投影到随转子旋转的 dq 坐标系上：d 轴对准转子 N 极，q 轴超前 90°。在 dq 坐标中稳态电流是直流量：

· id：与永磁磁场同向，调节磁场（表贴式电机取 0；弱磁时取负）
· iq：与永磁磁场正交，产生转矩 Te = Kt·iq

4. 电流环与速度环

dq 坐标下的电机电压方程：

ud = R·id + Ld·did/dt − ωeLqiq
uq = R·iq + Lq·diq/dt + ωe(Ldid + ψf)

两个 PI 分别控制 id、iq。取 Kp = L·ωc、Ki = R·ωc 可以抵消电机的电气极点，闭环成为带宽 ωc 的一阶系统；交叉耦合项 ωeLi 与反电势 ωeψf 用前馈解耦补掉。外面再套一个速度 PI，输出 iq*，形成串级控制。

5. SVPWM 与逆变器

电流 PI 输出 ud、uq，逆 Park 得到 uα、uβ，再由 SVPWM 算出三相占空比。逆变器的功率管只能全开或全关，靠 10–20 kHz 的高频开关和绕组电感的滤波作用，让电机“感受”到的平均电压等于指令。SVPWM 的线性调制范围为 |u| ≤ Vdc/√3。

6. 数字控制的细节

· 采样时刻：在载波顶点（零矢量 000 中点）采样电流，此时纹波恰好过平均值；
· 一拍延时：本周期算出的占空比下周期才生效，加上 PWM 的平均延时共约 1.5 Ts，高速时用角度补偿 θ + 1.5ωeTs；
· 抗积分饱和：电压矢量限幅到 Vdc/√3 的圆内，饱和期间停止向外积分；
· 编码器零位：θ 有偏差时电流矢量不再落在 q 轴上，同样电流转矩变小，还会出现不需要的 id。

关于本仿真

电气部分为开关级模型：每个 PWM 周期按占空比切成最多 7 段恒定开关状态，段内用 RK2 积分 PMSM 的 dq 方程，因此电流纹波、调制饱和、数字延时都是“算”出来的，而非画出来的。2D 磁场剖面采用解析的气隙磁密 + 磁通函数模型（非有限元），用于定性展示磁路与磁力线走向。所有方程与参数见 js/core/，单元测试见 tests/。
