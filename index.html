① 控制指令 你给定的目标

速度闭环：PI 调节器自动算出转矩电流 iq*。点“磁场对齐演示”可手动拨动定子矢量，直观感受 iq 与转矩的关系。

② 控制流水线 实时数值

速度PI → iq* = 0.00 A，id* = 0.00 A
逆Park (dq→αβ) 用 θe 旋转 → iα=0, iβ=0
逆Clarke / SVPWM → 三相占空比
逆变器+电机 → 实际三相电流
采样 + Clarke (abc→αβ) →回到 iαiβ
Park (αβ→dq) 用 θe → id=0, iq=0 ↺反馈

③ 三相电流 ia ib ic 物理量 (静止)

三个互差 120° 的交流量。频率随转速变化，幅值随负载变化——直接看很难判断该怎么控制。

d/q 坐标系跟着转子一起转，所以稳态下 id、iq 变成了直流量——这就是 FOC 能像控制直流电机一样控制交流电机的关键。

FOC 到底在做什么？

问题：交流电机的三相电流是耦合的交流量，转矩和磁场纠缠在一起，没法直接控制。

思路：站到转子的视角上看（旋转坐标系 d-q）。在这个视角里电流不再交变，分解成两个独立直流分量：

· id：沿磁极方向 → 控制磁场（一般设 0，不做无用功）
· iq：垂直磁极方向 → 控制转矩（Te ∝ iq）

做法：想要多大转矩就给多大 iq，PI 控制器算出 dq 电压，再经逆 Park / 逆 Clarke / SVPWM 变回三相去驱动。形象地说：始终让定子磁场超前转子磁场 90°，像永远使最大力气推磨。
