# FOC 磁场定向控制 · 交互式仿真 `v1.2`

**在线体验：** https://liyucheng1997.github.io/47_demo-foc-motor/

一个在浏览器里运行的永磁同步电机（PMSM）**磁场定向控制（FOC）** 教学仿真平台：底层是**开关级逆变器 + PMSM 动态模型**的实时数值仿真，上层用 3D 电机模型、2D 磁力线剖面、控制框图、示波器和分步讲解把“三相电流 → Clarke → Park → PI → SVPWM → 逆变桥 → 旋转磁场 → 转矩”的完整链路讲清楚。

## 运行

纯前端、无构建。由于脚本拆分为多个文件，建议用本地服务器打开：

```bash
python tools/serve.py        # 然后访问 http://localhost:8137
```

也可以直接双击 `index.html`（经典 `<script>` 加载，`file://` 下同样可用）。Three.js 从 CDN 加载，需要联网。

运行单元测试（Node ≥ 18，无依赖）：

```bash
npm test
```

## 功能

### 仿真内核（`js/core/`）
- **开关级逆变器**：中心对齐 PWM，每个开关周期按三相占空比切成最多 7 段恒定开关状态，段内用 RK2 积分电机方程——PWM 电流纹波、调制饱和都是“算”出来的。
- **PMSM dq 模型**：R、L<sub>d</sub>、L<sub>q</sub>、ψ<sub>f</sub>、反电势、交叉耦合，机械方程含转动惯量、粘滞摩擦、恒转矩/风机负载，或由测功机强制转速。
- **数字 FOC 控制器**：载波顶点（零矢量中点）采样、一拍计算延时 + 1.5T<sub>s</sub> 角度补偿；电流 PI 按 K<sub>p</sub>=Lω<sub>c</sub>、K<sub>i</sub>=Rω<sub>c</sub> 自动整定，dq 解耦 + 反电势前馈，电压矢量圆限幅 + 条件积分抗饱和；速度 PI + 斜坡；电压反馈自动弱磁；可注入编码器零位误差。
- **5 种运行模式**：速度闭环、转矩闭环、转矩–电流角实验（测功机堵转/拖动）、直流定位、I/f 开环（可演示失步）。

### 电机本体（`js/core/machine.js`）
- **7 种槽极方案**：6s2p（教学）、6s4p、9s6p、12s8p、9s8p、12s10p、12s14p。
- **槽电势星形图**自动生成双层集中绕组排布，计算分布系数 k<sub>d</sub>、节距系数 k<sub>p</sub>、绕组系数 k<sub>w</sub>、相轴电角、齿槽转矩周期。
- **按磁路尺寸化的几何**：轭厚按半个极的磁通、齿宽按齿距比例确定（2 极电机轭最厚），3D 与 2D 共用同一套几何。
- **气隙磁场模型**：表贴磁钢梯形波 + 齿 MMF 阶梯波（电枢反应），由此构造二维磁通函数 ψ(r,θ)。

### 可视化（`js/view/`）
- **3D 结构**：硅钢叠片定子（齿靴、槽型）、逐匝逐层建模的集中绕组、表贴磁钢转子、阶梯轴 + 键、滚珠轴承（保持架转速）、编码器码盘、带剖切口的散热机壳；支持**爆炸图**、**结构标注**、相机预设。叠加显示导体电流 ⊙/⊗、气隙磁场、定子电流矢量、d/q 轴、δ 夹角、星形连接三相母线。
- **2D 磁场剖面**：|B| 云图 + 磁力线（ψ 等值线，相邻两线磁通相等），可切换合成/仅永磁/仅电枢，鼠标悬停读数。
- **实时控制框图**：导线上显示各环节信号，模式不同自动灰显未用环节，点击方框跳转到对应图表。
- **示波器**：三相电流（可见 PWM 纹波）、dq 电流与指令、转速/转矩、电压需求，时间窗 1 ms ~ 4 s。
- **Clarke/Park 双视角**：静止坐标下三相矢量首尾相接合成 i<sub>s</sub>；转子坐标下 i<sub>s</sub> 静止为直流量。
- **气隙磁密展开图**、**dq 平面电流圆/电压圆**（弱磁原理）。
- **SVPWM 六边形**、**马鞍波**、**七段式载波比较**、**三相逆变桥**；慢放到 1/20000 时与仿真真实开关同步。
- **分步讲解**：13 步从“电机结构”讲到“弱磁”“编码器误差”，每步自动配置场景并高亮相关框图。

## 目录结构

```
index.html            页面布局
css/style.css         样式
js/core/foc-core.js   坐标变换、SVPWM、PI、FOC 控制器
js/core/machine.js    槽极方案、绕组、几何、气隙磁场与磁通函数
js/core/simulator.js  开关级逆变器 + PMSM 模型 + 记录器
js/view/*.js          3D 场景、磁场剖面、图表、框图
js/tour.js            分步讲解
js/app.js             界面绑定与主循环
tests/core.test.js    单元测试（变换、SVPWM、绕组系数、闭环性能、弱磁、失步、纹波）
tools/serve.py        无缓存本地开发服务器
```

## 模型说明与局限
- 电气参数为示意的小功率伺服电机（K<sub>t</sub> = 0.09 N·m/A，V<sub>dc</sub> = 48 V），不同方案按极对数缩放以保持外特性可比。
- 磁场剖面为解析模型（非有限元），用于定性展示磁路走向与磁密分布；未建模齿槽转矩、铁损、饱和与死区。

## 技术栈
- [Three.js](https://threejs.org/) r128（OrbitControls、BufferGeometryUtils、RoomEnvironment）
- 原生 JavaScript + Canvas 2D + SVG，无框架、无构建
