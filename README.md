# FOC 磁场定向控制 · 交互式可视化

一个基于 **Three.js** 的单文件交互式可视化，用来直观理解永磁同步电机（PMSM）的 **FOC（磁场定向控制）** 原理：从三相电流，经 Clarke / Park 坐标变换，到旋转磁场的产生与转矩的形成。

直接用浏览器打开 [`index.html`](index.html) 即可运行，无需任何安装或构建。

## 功能特性

### 3D 电机模型
- **叠片定子铁芯**：12 齿带齿槽截面，缠绕**按相染色的铜绕组**（A 红 / B 绿 / C 蓝），每个齿标注相别字母（`A` / `A′` 表示正向/反向回线）。
- **表贴永磁转子**：按极对数生成 `2p` 个交替磁极，**N 红 / S 蓝**并标注字母。
- **可切换的真实外壳**：带散热片的机壳、端盖、底座、接线盒。
- **三相母线（星形 Y 接法）**：U/V/W 进线 → 各相母线环 → 中性点 N。

### 物理量与控制可视化
- **电流环**：每个齿画出完整电流环（两条边 ⊙/⊗ + 端部缠绕方向箭头），可用右手定则验证磁场方向。
- **气隙旋转磁场**：由各齿实际电流插值得到（与右手定则自洽），箭头长度反映强弱，并标出最强等效 N / S 位置。
- **δ 夹角**：实时显示定子等效磁极与转子磁极的夹角（机械角 / 电角度），直观看到 FOC 维持的 ≈90° 电角领先。
- **三相电流波形** + **Clarke/Park 矢量平面**（αβ 静止系 / dq 旋转系）。
- 完整的**控制流水线**实时数值：速度PI → iq* → 电流环电压 → 逆Park → SVPWM 占空比 → 逆变桥 → 三相电流 → 采样Clarke → Park → dq 反馈。

### PWM / SVPWM 可视化
- **空间电压矢量六边形**：6 个基本矢量 + 零矢量、扇区实时高亮、U_ref 分解为 T1/T2/T0（伏秒平衡），黄点显示当前载波时刻实际输出的开关状态。
- **载波比较慢放**：三角载波与三相占空比比较生成中心对齐的七段式门极波形（000→100→110→111→…），每段标注开关状态，光标与其他图联动。
- **马鞍波占空比**：正弦 + 零序注入（等价 SVPWM），直观展示 15% 电压利用率提升。
- **三相逆变桥原理图**：6 个开关的实时通断状态（上下管互补）、相电流方向箭头、直流母线。
- 可调 **直流母线电压 V_dc**（调低可体验过调制限幅与警告）与载波慢放速度。

### 交互
- 调节：目标转速、负载转矩、励磁电流 i_d、**极对数 p**、直流母线电压 V_dc、载波慢放周期。
- 模式：速度闭环 / 手动磁场对齐演示。
- 开关：外壳、三相母线、合成磁场、电流方向、夹角 δ、暂停。
- 鼠标拖动旋转视角，滚轮在对齐演示模式下拨动定子矢量。

## 核心教学点

交流电机的三相电流是耦合的交流量，难以直接控制。FOC 的思路是站到**转子坐标系（d-q）**上看：电流分解成两个独立直流分量——`i_d`（控制磁场，通常设 0）和 `i_q`（控制转矩）。控制器实时测量转子位置，把定子电流矢量锁定在 q 轴上，等价于让定子的**异性磁极始终领先转子 90° 电角**，持续把转子"吸"着转。
